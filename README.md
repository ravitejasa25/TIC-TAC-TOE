# Tic-Tac-Toe Game

An interactive web-based **Tic-Tac-Toe Game** built using **HTML, CSS, and JavaScript**.
This project provides a fun and responsive gaming experience with multiple game modes, score tracking, and smart AI gameplay.

## Features

* Interactive 3x3 game board
* Player vs Player mode
* Player vs Computer mode
* Smart AI opponent (Minimax algorithm)
* Winner detection
* Draw detection
* Scoreboard tracking
* Restart game option
* Reset scoreboard option
* Responsive design for desktop and mobile

## Game Modes

### Player vs Player

* Two players take turns playing X and O

### Player vs Computer

* Play against AI
* Basic mode (random moves)
* Smart mode (Minimax strategy)

## How to Run

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser

## How to Play

1. Choose game mode
2. Click on an empty cell to place your mark
3. Complete a row, column, or diagonal to win
4. If all cells are filled without a winner, the game is a draw

## Game Rules

* Players alternate turns
* X starts first
* First player to align 3 symbols wins
* No overwriting filled cells
* Draw if all cells are filled and no winner
